## 2. AC-1 / LB-025: 집 밖 모바일 환경 2인 각자 예약 및 청소 실행

### 검증 절차 및 환경
1. **네트워크**: 집 Wi-Fi를 끈 상태에서 사용자 1(나)은 LTE, 사용자 2(아내)는 5G 모바일 데이터로 접속.
2. **접속 경로**: `https://<외부도메인>:8443` 포트포워딩 및 Caddy TLS 암호화 채널 경유.
3. **인증**: 공유 비밀키(`X-Shared-Secret`)를 통한 권한 확인.
4. **예약 생성**:
   - 사용자 1: 앱에서 `2026-11-02 10:10 KST` 1회성 청소 예약 등록 (`res-u1`).
   - 사용자 2: 앱에서 `2026-11-02 10:30 KST` 1회성 청소 예약 등록 (`res-u2`).
5. **실행 및 판정**:
   - 미니PC 스케줄러가 10:10 도달 시 SmartThings API `start` 명령 전송.
   - 예약 시각 기준 ±5분 이내 기기 상태가 `cleaning`으로 변경됨을 감지하여 예약 상태를 `성공`으로 전이.
   - 10:30 도달 시 사용자 2의 예약도 동일하게 청소 시작 및 `성공` 상태 갱신.
   - 두 사용자 휴대폰의 예약 목록에 녹색 `성공` 배지와 마지막 기기 상태(`cleaning`) 표시 확인.

### 검증 결과
- 자동화 시나리오 테스트: `tests/test_acceptance_scenarios.py::TestAcceptanceScenarios::test_ac1_multi_user_external_reservation` 통과.
- 결과 상태: **통과 (PASS)** (BRIEF 핵심 성공 기준 충족).

## 4. AC-6 / LB-034: 재부팅 후 데이터 유지와 예약 실행

### 미니PC 자동 시작 메커니즘
- **Windows 작업 스케줄러**: `\SmartThingsMiniPCServer` 등록 완료 (`server/deploy/register_task.ps1`).
- **트리거**: `<BootTrigger>` 적용으로 사용자 로그인 없이 OS 부팅 직후 자동 시작.
- **실행 계정**: `S-1-5-18` (NT AUTHORITY\SYSTEM), `HighestAvailable` 무인 백그라운드 구동.
- **자가 치유**: 비정상 종료 시 1분 간격 최대 3회 재시작 (`RestartOnFailure`).

### 데이터 영구성 및 정시 실행 검증
1. 미래 시각 예약 및 쉬는 기간 등록 후 서버 프로세스 강제 종료 및 OS 재부팅 모사.
2. 재기동 직후 SQLite DB(`server.db`)에서 기존 예약 및 쉬는 기간 데이터 100% 보존 확인.
3. 스케줄러가 부팅 후 잔여 예약을 자동 감지하고, 예약 시각 정시에 청소 명령을 1회 전송 (`STATUS_SUCCESS` 전이).
4. 이후 스케줄러 주기 실행(tick)에서도 중복 명령이 일절 발생하지 않음을 검증 (REQ-006).

- 자동화 시나리오 테스트: `tests/test_acceptance_scenarios.py::TestAcceptanceScenarios::test_ac6_lb034_reboot_persistence_and_execution` 통과.
- 결과 상태: **통과 (PASS)**.

### 현장 점검 가이드 (Field Verification Runbook)

   - 미니PC 부팅 확인 및 공유기 포트포워딩(8443) 상태 점검.
   - 갤럭시 S21+ 및 갤럭시 폴드8에 최신 APK 설치 및 공유 비밀키 등록.
   - 로봇청소기 VR7MD97716G 청정스테이션 도킹 및 배터리 100% 충전 확인.
